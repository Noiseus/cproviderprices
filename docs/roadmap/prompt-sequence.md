# Prompt Sequence

- **Prompt 00 — Persistent project contract/documentation:** establish repository instructions, product and architecture direction, data/security/integration/UX principles, deployment context, ADR process, and roadmap. This is the current stage.
- **Prompt 01 — Initial monorepo/application scaffolding and local development foundation:** create the approved initial applications and development orchestration when explicitly requested.
- **Later prompts:** authentication and multi-tenancy, data model, supplier ingestion, API contracts, UI foundation, comparison workflows, testing, observability, security hardening, deployment, and subsequent MVP capabilities.

Later items are themes only. Their detailed requirements and order remain unresolved until their prompts are provided; do not preemptively implement or invent them.
